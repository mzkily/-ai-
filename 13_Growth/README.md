# 13_Growth — 个人成长系统

> 第 13 个分区。通过长期记录、分析和复盘，帮助发现成长趋势、识别优势与短板、积累可复用经验、避免重复犯错、形成个人知识资产。
> 目标是让我成为一个「构建个人 AI 工作系统的人、持续学习和成长的学生、未来可能探索 AI 自动化 / 技术项目 / 商业机会的人」。

## 核心目标
1. 发现自己的成长趋势
2. 识别优势与短板
3. 积累可复用经验
4. 避免重复犯错
5. 形成个人知识资产
6. 辅助未来学习、项目与职业发展

## 重要原则
1. 不鼓励「为了学习工具而学习工具」。
2. 关注长期能力，而不是短期信息。
3. 如果发现我沉迷研究系统/模型/工具、缺少实际产出 → 提醒我。
4. 如果发现某件事可能形成项目/作品/案例/商业价值 → 标记。
5. 不替我做人生决定，但提供分析。
6. 每种积累都归类到对应的 12 个目录或第 13 个（本区）里去，具体由 AI 分析归属。

> **最高目标**：帮助我建立「长期复利能力」。

## 个人成长复盘工作流

### 目标
定期总结我的成长轨迹，沉淀经验和资产，帮助我持续优化学习、工作和发展方向。

### 复盘工作流原则
- 关注**成长**，不只是完成任务
- 关注**积累**，不只是记录信息
- 关注**长期价值**，不只是短期效率

### 每周复盘（Weekly Review）——每周执行一次
根据本周记录生成：
1. **本周总结**：完成的重要事项 / 学习与实践成果 / 值得记录的经历
2. **成长分析**：新增了哪些能力？哪些方面有所提升？哪些问题反复出现？
3. **经验沉淀**：本周最值得保存的方法/技巧/经验/认知变化；如有价值，存入 Personal_AI_OS 对应位置
4. **下周建议**：3 个优先事项 / 需要改进的问题 / 应该减少或停止的事情

### 每月复盘（Monthly Review）——每月执行一次
做更深层分析：
1. **月度总结**：本月主要投入 / 重要成果 / 关键事件
2. **能力成长**：哪些能力正在形成？哪些值得继续投资？我的优势是否更加明显？
3. **资产积累**：新增知识 / 新技能 / 项目经验 / 可复用方法；判断哪些值得长期保存
4. **问题与调整**：最大的问题是什么？哪些时间投入收益低？是否偏离长期目标？
5. **下月规划**：核心目标 / 重点任务 / 成长方向

### 记录原则
不记录所有事情，只沉淀：
- ✅ 能提升能力的经历
- ✅ 可复用的方法经验
- ✅ 重要决策和反思
- ✅ 项目成果和案例
- ✅ 对未来有价值的认知

## 知识资产分层
- 信息：只是知道
- 知识：理解并可以使用
- 经验：经过实践总结
- 资产：可以重复利用并产生价值
- **优先沉淀：经验 > 知识 > 信息**

## 最终目标
> 让 Personal AI OS 随着时间积累，逐渐成为了解我、帮助我成长的个人系统。
