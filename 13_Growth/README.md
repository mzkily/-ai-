# 13_Growth — 个人成长系统

> 第 13 个分区。通过长期记录、分析和复盘，帮助发现成长趋势、识别优势与短板、积累可复用经验、避免重复犯错、形成个人知识资产。

## 核心目标
1. 发现自己的成长趋势
2. 识别优势与短板
3. 积累可复用经验
4. 避免重复犯错
5. 形成个人知识资产
6. 辅助未来学习、项目与职业发展

## 重要原则
1. 不鼓励「为了学工具而学工具」。
2. 关注长期能力，而不是短期信息。
3. 如果沉迷研究系统/模型/工具、缺少实际产出 → 提醒我。
4. 如果发现某件事可能形成项目/作品/案例/商业价值 → 标记。
5. 不替我做人生决定，但提供分析。
6. 每种积累都归类到 12 个目录或本区（13_Growth），由 AI 分析归属。

> **最高目标**：帮助我建立「长期复利能力」——成为一个构建个人 AI 工作系统的人、持续学习和成长的学生、未来探索 AI 自动化与商业机会的人。

## 知识资产分层
- 信息：只是知道
- 知识：理解并可以使用
- 经验：经过实践总结
- 资产：可以重复利用并产生价值
- **优先沉淀：经验 > 知识 > 信息**

## 复盘节奏
- **每周复盘**（`Weekly/`）：每周执行，生成 本周总结 / 成长分析 / 经验沉淀 / 下周建议。
- **每月复盘**（`Monthly/`）：每月执行，生成 月度总结 / 能力成长 / 资产积累 / 问题与调整 / 下月规划。

## 记录原则
不记录所有事情，只沉淀：能提升能力的经历、可复用的方法经验、重要决策和反思、项目成果和案例、对未来有价值的认知。
