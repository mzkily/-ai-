# Personal AI OS — 个人 AI 操作系统

> 不是「笔记库」，而是你的「私人 AI 大脑」：让 Mika、MiMo、DeepSeek、Codex、GPT 等快速理解你是谁、你做什么、你有什么资产、未来往哪发展。

## 目录
```
00_System  系统层：AI 的人格 API（AI 先读这里）
01_Self    自我认知：我是谁
02_Learning 学习系统：我在学什么（核心）
03_Skills   能力树：我会什么
04_Work     工作：可复用的流程与模板（未来的商业资产）
05_Projects 项目：Active / Completed / Ideas
06_AI_Team  AI 团队：Agents / Prompts / Workflows / Models / Experiments
07_Knowledge 知识沉淀：经过我理解后的知识（不是原文收藏）
08_Resources 资源库：原材料（Books/Papers/Courses/Tools，可以乱）
09_Ideas    想法库：Business / Project / Learning / Random
10_Life     生活：规划、习惯、偏好（不记敏感隐私）
11_Finance  财务：Income / Expense / Investment / Business
12_Archive  归档：所有旧东西，不删除
```

## AI 读取顺序
- **Mika（项目管理）**：`00_System` → `01_Self` → `05_Projects` → `06_AI_Team` → 具体任务
- **MiMo（技术分析）**：`00_System` → `03_Skills` → `07_Knowledge` → 技术任务
- **DeepSeek（执行）**：项目文件 → 任务说明 → 执行
- 通用入口：任何 AI 开工前先读 `00_System/AI_README.md`

## 维护节奏（不要一开始就填满）
- **第一周（先让 AI 认识你）**：00_System、01_Self、02_Learning、06_AI_Team
- **第二阶段（沉淀资产）**：05_Projects、04_Work、07_Knowledge
- **第三阶段（寻找变现）**：09_Ideas、11_Finance
- 每天随手记：`00_System/Daily_Log.md`；犯错记 `Mistake_Database.md`；资产变化记 `Asset_Index.md`

## 目标
坚持维护 1 年 → 一个拥有你 1 年思考、学习轨迹、项目经验、工作流的私人 AI 大脑。
