# 函数

## 概念
- 函数 = 输入（参数）→ 处理 → 输出（返回值），把一段逻辑包起来复用。
- 声明（`int add(int a, int b);`）→ 定义（`{...}`）→ 调用（`add(1,2)`）。
- **值传递**：默认传的是副本，函数里改参数不影响外面；想改外面就传指针（见 指针.md）。

## 例子（入门第一个函数程序：判断素数）
```c
#include <stdio.h>

// 判断 n 是不是素数：是返回 1，不是返回 0
int is_prime(int n) {
    if (n < 2) return 0;
    for (int i = 2; i * i <= n; i++) {   // 只需要试到根号 n
        if (n % i == 0) return 0;
    }
    return 1;
}

int main() {
    for (int n = 2; n <= 50; n++) {
        if (is_prime(n)) printf("%d ", n);
    }
    printf("\n");
    return 0;
}
```
**用途**：把「判断素数」这种逻辑写成函数后，主程序里随时调用，不用重复写。

## 易错点
- **值传递改不到外面**：函数里 `x = 10;`，外面 x 不变；要改就用指针（`swap` 例子见 指针.md）。
- **忘记 return 或 return 类型不匹配**：`int` 函数必须返回整数，漏 return 结果是垃圾值。
- **只声明不定义**：调用了没实现/没声明的函数 → 编译报错。
- **`return` 一执行函数就结束**：后面写的代码不会跑，别把逻辑放在它后面。
