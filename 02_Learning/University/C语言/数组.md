# 数组

## 概念
- 数组是一段**连续内存**里的同类型数据，下标从 **0** 开始：`int a[5]` 是 a[0]~a[4]。
- 数组名就是**首元素地址**（`a` 等价于 `&a[0]`），传给函数时退化成指针。
- 常用写法：`int a[5] = {1,2,3};` 没写全的部分自动补 0。

## 例子（入门第一个数组程序：统计班级成绩）
```c
#include <stdio.h>

int main() {
    int scores[5] = {78, 92, 60, 85, 55};   // 5 个同学的成绩
    int sum = 0, max = scores[0];

    for (int i = 0; i < 5; i++) {           // 循环遍历
        sum += scores[i];
        if (scores[i] > max) max = scores[i];
    }

    printf("平均分: %.1f\n", sum / 5.0);    // 注意除 5.0 而不是 5（否则整数除法）
    printf("最高分: %d\n", max);
    return 0;
}
```
**用途**：成绩统计、排序、查找——凡是「一批同类型数据」都先用数组。

## 易错点
- **越界**：`int a[5]` 访问 a[5] 是越界（合法范围 0~4），不报错但会改到别的内存，很难查。
- **下标从 0 开始**：循环 `for (i = 0; i < n; i++)`，写成 `i <= n` 就多读一位。
- **数组名不能整体赋值/比较**：`a = b;` 和 `a == b;` 都是错的，要逐元素赋值/比较或用 `memcpy`/`strcmp`。
- **数组名作参数是传地址**：函数里改了数组，外面也变（跟普通变量传值不一样）。
