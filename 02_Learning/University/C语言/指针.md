# 指针

## 概念
- 指针是**存地址的变量**：`int *p = &a;` 表示 p 里存的是 a 的地址。
- `&` 取地址，`*` 解引用（按地址找到那个变量）。
- 为什么需要指针：函数间共享数据、动态内存、数组/字符串操作都靠它。

## 例子（入门第一个指针程序：函数里修改外面的变量）
```c
#include <stdio.h>

// 普通传值：改的是副本，外面不变
void bad_swap(int x, int y) {
    int t = x; x = y; y = t;
}

// 传指针：改的是实参本身
void swap(int *x, int *y) {
    int t = *x; *x = *y; *y = t;
}

int main() {
    int a = 3, b = 5;
    bad_swap(a, b);
    printf("bad_swap 后: a=%d b=%d\n", a, b);  // 3 5（没换成功）
    swap(&a, &b);
    printf("swap 后: a=%d b=%d\n", a, b);      // 5 3（换成功了）
    return 0;
}
```
**用途**：只要想「函数里改了、外面要生效」，就传指针——这是 C 里最常见的指针用法。

## 易错点
- **野指针**：声明了没赋值就解引用，如 `int *p; *p = 10;` → 崩溃。初始化 `int *p = NULL;`。
- **`&` 和 `*` 混用**：`scanf("%d", &x)` 必须写 `&x`（scanf 要的是地址）；`printf("%d", *p)` 解引用才有值。
- **指针类型要匹配**：`int *p` 不能去存 `double` 变量的地址，类型不对会读错数据。
- **不要解引用 NULL**：`if (p != NULL)` 判断后再用。
