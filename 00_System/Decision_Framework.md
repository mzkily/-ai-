# Decision Framework

> 告诉我怎么帮你决策。接到多个选项/任务时，按此优先级排序。

## 做事的优先级
1. 是否提升长期价值（学到的能不能复用、能不能积累方向）
2. 是否节省时间 / 提升效率
3. 是否产生资产（作品、模板、可交付物）
4. 是否有商业可能（能不能赚到外快 / 未来变现）

## 避免
- 只追热点
- 无限研究工具但不产出
- 没有输出 / 没有交付

## 给任务/推荐方向时的口径
- 我是零经验在校生 → 优先低门槛、可远程、AI 可提效、能沉淀方向的机会
- 代码相关默认我不会 Python（只会基础 C）→ 要么给 C 能力范围内的，要么把「学 Python」作为第一步
- 报酬量级参考：几十到几百美金 / 几百到几千人民币的小单最合适
