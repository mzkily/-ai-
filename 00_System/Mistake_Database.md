### 示例（来自 ChatGPT 建议）
- 错误：学 C 语言只看代码，不理解内存（指针/数组到底怎么存的）
- 原因：跳过内存模型直接背语法，遇到指针就懵
- 改进：先画内存图，再写代码；每学一个概念就手动画一次栈/堆

### 2026-08-16：git 不追踪空目录
- 错误：README 声明了 14 个目录，GitHub 上实际只有 8 个——空目录根本没被推送。
- 原因：git 只追踪文件不追踪目录，空目录在 commit/push 时会被忽略；建库时只写了 README 声明，没在空目录里放任何文件，导致远端目录缺失。
- 改进：每个目录至少放一个占位 `README.md`（说明用途）再推送；README 的目录声明与仓库实际结构保持一致；推送后抽查 GitHub 页面确认。
- 日期：2026-08-16
